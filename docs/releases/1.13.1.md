Requested by the repository maintainer in this chat on 2026-10-26: update
dependencies, migrate xUnit and API versioning, bump the version, commit, tag,
and push. Release tag: `v1.13.1`. Previous release: `v1.13.0`.

## Security and deployment

The changes update identity-client, logging, SQLite, and build dependencies.
Authentication policies, endpoint permissions, certificate pinning, and secret
storage are preserved. No database schema migration is required.

For an FGV deployment, classification is proposed as level 4, subject to ESI
validation against the actual data inventory. Production security verification,
the system/user homologators, the deployment coordinator, and any required
change-request identifier remain with the deployment owner; this source release
does not record or grant those approvals. No production deployment is performed
by this change. The inaccessible G-002 v2 and organization-specific requirements
must be checked by that owner where applicable.

## Rollback

Build and redeploy `v1.13.0` with that release's SDK and dependency versions,
preserving the deployed configuration and secret store. This also restores the
older dependency vulnerabilities, so reassess exposure before rollback.
