## Security and deployment

Authentication policies, endpoint permissions, certificate validation, secret
derivation, and database schemas are preserved. No dependency update or database
migration is part of this release.

For an FGV deployment, the proposed level 4 classification remains subject to
ESI validation against the actual data inventory. Production security verification,
system/user homologation, deployment authorization, and a change-request identifier
remain with the deployment owner. This source release grants none of those
approvals and performs no production deployment. Organization-specific requirements
and the inaccessible G-002 v2 must be checked by that owner where applicable.
